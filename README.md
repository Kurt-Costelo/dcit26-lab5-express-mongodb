# DCIT 26 - Laboratory 5: Express and MongoDB

A REST API that manages student records built with Node.js, Express, MongoDB, and Mongoose.

## Setup Instructions
1. Clone this repository.
2. Run `npm install` in your terminal to install the dependencies.
3. Ensure MongoDB Community Server is installed and running locally.

## MongoDB Configuration
Rename `.env.example` to `.env` and include your local connection string:# dcit26-lab5-express-mongodb
